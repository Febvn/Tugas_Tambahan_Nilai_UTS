Sequence Form Features

  • Form Title: Required title for the form
  • Items: Dynamic list of name-value pairs
  • Add/Remove: JavaScript-powered item management
  • Validation: Each item validated individually

How to Use

  1. Enter a title for your form
  2. Click "Add Item" to add name-value pairs
  3. Fill in the name and value for each item
  4. Use the remove button to delete items
  5. Submit when you have all desired items

Technical Details

class SequenceForm(colander.MappingSchema):
    title = colander.SchemaNode(colander.String())
    items = colander.SchemaNode(
        colander.Sequence(),
        SequenceItem(),
        widget=deform.widget.SequenceWidget(min_len=1, max_len=10)
    )
